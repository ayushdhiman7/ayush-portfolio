# Nirdesh AI: Multilingual Voice Agent

## Overview

Nirdesh AI is an instrumented multilingual voice agent built as a sandwich architecture: streaming speech-to-text feeds a LangGraph-backed text agent, then streaming text-to-speech returns PCM audio to the browser over an authenticated WebSocket.

## Features

- **Multilingual voice loop**: Saaras v3, `sarvam-105b`, and Bulbul v3.
- **Silero ONNX VAD**: Local 32 ms frames, speech pre-roll, 500 ms endpointing, and silence gating.
- **Barge-in control**: Cancels generation, tears down active TTS sockets, flushes browser playback, and truncates assistant history.
- **LangChain tools**: Server-side Exa web search and browser-proxied local todos.
- **Wallet & session billing**: Paise-denominated wallet with per-second voice billing and auto-cutoff.
- **Full instrumentation**: TurnTimer metrics, structured logs, and client latency waterfalls.
