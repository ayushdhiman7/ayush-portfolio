# Drug Discovery: Multi-Agent Target Prioritisation

## Overview

Drug Discovery Agent automates end-to-end drug-target prioritisation with a LangGraph orchestrator, MCP-connected biomedical data sources, deterministic scoring, and human-in-the-loop review gates.

## Key Features

- **LangGraph pipeline**: Planning → parallel collection → normalisation → scoring → evidence graph → synthesis.
- **MCP data layer**: Parallel queries across DepMap, Pharos, Open Targets, and Europe PMC.
- **Deterministic scoring**: Weighted multi-source druggability scores with conflict detection and tiering.
- **5-layer memory**: Episodic, working, semantic, procedural, and content memory for reproducibility.
- **Human-in-the-loop**: Optional plan approval and review gates before final dossier acceptance.
- **Research workbench**: FastAPI + Next.js UI with live SSE progress, evidence carousel, and follow-up Q&A.
