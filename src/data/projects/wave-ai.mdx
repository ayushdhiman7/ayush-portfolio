# Brainwave: AI Chat Application

## Overview

Brainwave is a modern AI-powered chat application that lets you explore the possibilities of AI chatting. Built with a sandbox architecture featuring a React frontend, Vite build tool, and Tailwind CSS styling, it provides a seamless conversational AI experience with context-aware responses and a clean, intuitive interface.

## Features

- **AI Chat**: Powerful AI conversations with context awareness using Hugging Face inference
- **Responsive Design**: Works beautifully on mobile and desktop
- **Modern UI**: Clean, intuitive interface built with Tailwind CSS
- **Route-based Navigation**: Home, Pricing, Roadmap, and Chat pages
- **AI-powered Features**: Smart chatbot with personalized recommendations

## Technology Stack

Brainwave leverages a modern web development stack:

- **React** - For the user interface
- **Vite** - Fast build tool and development server
- **Tailwind CSS** - Utility-first CSS framework
- **Node.js** - Runtime environment
- **Express** - Web framework for the server
- **Hugging Face** - AI model inference and APIs
- **React Router** - Page navigation and routing

## Getting Started

Brainwave is easy to set up and run locally:

1. Clone the repository
2. Install dependencies with `npm install`
3. Start the development server with `npm run dev`
4. Open your browser to view the application

The application is designed to be extensible, allowing you to add new features, integrate additional AI capabilities, or modify the existing functionality to suit your needs.
